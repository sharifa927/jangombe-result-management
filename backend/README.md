# Jang’ombe backend

This is the first backend step for the school system.

## Stack
- Node.js + Express
- TypeScript
- In-memory mock data (no database yet)

## Available routes
- GET /api/health
- POST /api/auth/login
- GET /api/teachers
- GET /api/classes
- GET /api/subjects
- GET /api/students
- GET /api/marks
- GET /api/submissions
- GET /api/teachers/:teacherId/submissions
- POST /api/submissions
